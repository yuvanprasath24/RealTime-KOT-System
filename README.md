# Restaurant QR Ordering System - Backend

Spring Boot backend for a QR-based restaurant ordering system.

## Features

- JWT Authentication
- QR Code Ordering
- Kitchen Dashboard
- Order Management
- Table Management
- WebSocket Real-time Updates
- Swagger/OpenAPI Documentation

## Frontend Repository

The React frontend is maintained in a separate repository.

Clone it from:
[Realtime-KOT-System_frontend](https://github.com/yuvanprasath24/RealTime-KOT-System-Frontend)

## Tech Stack

- Spring Boot
- Spring Security
- PostgreSQL
- WebSocket (STOMP)
- Swagger/OpenAPI
- Maven

## API Documentation

Swagger UI:

http://localhost:8080/swagger-ui/index.html

## Running the Project

1. Clone this repository.
2. Configure PostgreSQL.
3. Update `application.yml`.
4. Run the Spring Boot application.
5. Clone and start the frontend repository.
